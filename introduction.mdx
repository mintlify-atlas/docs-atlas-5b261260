Magazine Web PPT Skill is a structured AI agent skill for Claude Code that generates a complete, self-contained HTML presentation from a single prompt conversation. The output is a single `.html` file — no build tools, no server, no export step — styled in a "electronic magazine × e-ink" aesthetic: think *Monocle* magazine rendered in code. Claude reads `SKILL.md`, runs a six-step workflow on your behalf, and hands you a ready-to-present deck with WebGL fluid backgrounds, a strict three-tier typography system (Noto Serif SC + Playfair Display for headings, Noto Sans SC + Inter for body, IBM Plex Mono for metadata), and horizontal swipe navigation.

## When to use

<AccordionGroup>
  <Accordion title="Good scenarios">
    - Conference talks, industry keynotes, and private meetups
    - AI product launches and demo days
    - Presentations with strong personal voice and editorial style
    - Any deck you want to deliver as a shareable URL — no PPT viewer required
  </Accordion>
  <Accordion title="Not a good fit">
    - Large tables of data or heavily annotated charts (use a conventional PPT tool)
    - Training materials where information density must be high
    - Decks that multiple people need to co-edit (the output is static HTML)
  </Accordion>
</AccordionGroup>

## Aesthetic philosophy

The visual language was distilled from five rounds of real conference deck iteration. Violating any of these principles causes the visual quality to collapse:

1. **Restraint over showmanship** — The WebGL background is visible only on hero slides; content slides are nearly invisible to the shader. Animation serves emphasis, not entertainment.

2. **Structure over decoration** — No drop shadows, no floating cards, no padding boxes. All information hierarchy is communicated through large type, font contrast, and grid whitespace.

3. **Typography defines content hierarchy** — Largest serif = primary heading. Medium serif = subhead. Large sans-serif = lead copy. Small sans-serif = body. Monospace = metadata. Font choice is not decorative — it is structural.

4. **Image as first citizen** — Images are never cropped at the top or sides, only at the bottom if necessary. In grid layouts, height is fixed with `height:Nvh`; `aspect-ratio` is never used because it breaks the grid.

5. **Rhythm via hero pages** — Hero slides and content slides must alternate. Three or more consecutive slides of the same type cause visual fatigue. The hero/non-hero cadence is what gives a deck its pace.
