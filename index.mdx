Magazine Web PPT Skill is an AI agent skill for Claude Code that generates polished, single-file HTML presentations. The output aesthetic is a cross between *Monocle* magazine and e-ink displays — serif headings, WebGL fluid backgrounds on hero slides, and a strict typography hierarchy that makes slides feel editorial rather than corporate. Every deck is a self-contained HTML file: no build tools, no server, just open in a browser.

## What you get

Each generated deck includes everything pre-wired in a single HTML file:

- **WebGL fluid backgrounds** — animate on hero slides, near-invisible on content slides
- **Three-tier typography** — Noto Serif SC + Playfair Display for headings, Noto Sans SC + Inter for body, IBM Plex Mono for metadata
- **Horizontal swipe navigation** — keyboard `←` `→`, scroll wheel, touch swipe, dot indicators, `ESC` index view
- **5 curated color themes** — Ink Classic, Indigo Porcelain, Forest Ink, Kraft Paper, Dune. No custom hex values; the presets protect the aesthetic
- **10 slide layout skeletons** — paste-ready HTML for every common slide type

## When to use this skill

<Steps>
  <Step title="Tell Claude Code what you want to present">
    Trigger the skill with phrases like "make a magazine-style PPT" or "generate a horizontal swipe deck". Claude will clarify audience, duration, content, and theme.
  </Step>
  <Step title="Claude copies and configures the template">
    The skill copies `assets/template.html` to your project directory, sets the `<title>`, and applies your chosen color theme.
  </Step>
  <Step title="Slides are filled using layout skeletons">
    Claude picks from 10 layout types — cover, act dividers, data stats, pipelines, image grids, quotes, and more — and adapts them to your content.
  </Step>
  <Step title="Open in any browser">
    No build step. No server. Open `index.html` directly and present.
  </Step>
</Steps>

<Note>
This skill is designed for editorial-style presentations: conference talks, product launches, internal shares, and demo days. It is not suited for dense data tables, training materials, or collaborative editing workflows.
</Note>
