Magazine Web PPT ships with exactly five preset color themes. There are no custom hex values — the presets exist because color balance in the magazine × e-ink aesthetic is extremely sensitive. Swapping even one variable from a different theme breaks the contrast ratios and warmth tuning that make the deck feel cohesive.

## How to apply a theme

<Steps>
  <Step title="Open your copied index.html">
    Open the copied `项目/XXX/ppt/index.html` (not the original `assets/template.html`) in your editor and locate the `<style>` block.
  </Step>
  <Step title="Find the :root block">
    At the top of the `<style>` block, find the `:root {` declaration. The theme variables are annotated with a comment marking them as the theme color section.
  </Step>
  <Step title="Replace all 6 theme variable lines">
    Replace the entire block of six variables — `--ink`, `--ink-rgb`, `--paper`, `--paper-rgb`, `--paper-tint`, and `--ink-tint` — with the values for your chosen theme. All other CSS uses `var(--...)` references, so no other changes are needed.
  </Step>
</Steps>

## The 5 themes

<Tabs>
  <Tab title="Ink Classic">

### 墨水经典 (Ink Classic)

**Best for:** general presentations, commercial launches, tech products — the safe default for any subject matter.

**Aesthetic:** pure ink black paired with warm off-white. The strongest magazine feel of all five themes. Evokes Monocle, Apricot, and A Book Apart.

```css
--ink:#0a0a0b;
--ink-rgb:10,10,11;
--paper:#f1efea;
--paper-rgb:241,239,234;
--paper-tint:#e8e5de;
--ink-tint:#18181a;
```

  </Tab>
  <Tab title="Indigo Porcelain">

### 靛蓝瓷 (Indigo Porcelain)

**Best for:** tech, research, AI and data topics, engineering culture, deep content, technical conference decks.

**Aesthetic:** deep indigo paired with porcelain white. Cool, rational, and precise — like an academic journal or blue-and-white ceramic.

```css

--paper:#f1f3f5;
```

## Choosing a theme

| If your content is... | Recommended theme |
|---|---|
| Anything / first time / unsure | Ink Classic |
| AI / tech / product launch | Indigo Porcelain |
| Content analysis / industry observation / culture | Forest Ink |
| Book review / lifestyle / humanities | Kraft Paper |
| Design / art / brand / gallery | Dune |

## Hard rules

<Warning>
Do not mix variables from different themes. Even taking `--ink` from Ink Classic and `--paper` from Dune will look wrong — the contrast ratios and warmth levels are tuned as a complete system.
</Warning>

- **One theme per deck.** Do not change themes mid-deck. The theme sets the mood for the entire presentation.
- **No mixing variables across themes.** Every variable in a theme is calibrated against all the others. Taking one variable from a different theme breaks the balance.
- **Reject user-supplied hex values.** If a user asks for a custom color, decline politely and present the five presets for them to choose from.
- **Do not modify other color values in `template.html`.** All scattered `rgba()` values already use `var(--...)` references. Changing `:root` is the only edit needed.
- **WebGL shaders are tested against all 5 themes.** Both the titanium-dispersion (dark hero) and silver-flow (light hero) shaders produce acceptable results with every preset. No shader adjustments are needed when switching themes.
- **`currentColor`-driven borders and icons follow the section's text color automatically.** No extra adjustments needed after a theme switch.
