The big numbers layout is for presenting hard data that creates immediate impact. A grid of stat cards — each with a small English label, a large number, and a short note — delivers metrics at a glance without requiring the audience to read body text. Use it early in a deck to establish credibility with concrete evidence before moving into narrative slides.

**Default theme:** `light` (digits need a paper-white background for maximum contrast; you may occasionally insert `dark` for rhythm in multi-act decks)

## HTML skeleton

## Stat card structure

Each `.stat-card` follows a fixed three-layer hierarchy:

```
.stat-label   ← English small caps, names the metric
.stat-nb      ← the number itself (large, high-contrast)
  .stat-unit  ← optional unit suffix inline with the number
.stat-note    ← short description note below the number
```

## Grid options

| Class | Layout | Best for |
|-------|--------|----------|
| `.grid-6` | 3×2 | Six stats — the most common configuration |
| `.grid-4` | 2×2 | Four stats — when you want more breathing room per card |
| `.grid-3` | 3 columns, single row | Three stats — maximum impact per number |

## Number formatting

Keep numbers to 2–3 characters. Use K and M abbreviations (41K, 1.2M) rather than writing out full digits. Numbers longer than 5 characters will overflow the stat card on small screens.

<Warning>
Leave at least 5vh of top padding above the stat grid (`padding-top:6vh` on `.frame`) so the heading and lead paragraph claim visual priority before the grid appears. If the grid starts too close to the top of the slide, the numbers compete with the heading and neither wins.
</Warning>
