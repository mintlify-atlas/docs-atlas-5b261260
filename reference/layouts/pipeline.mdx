title: "Layout 6: Two-column pipeline (workflow steps)"
description: "Sequential workflow layout with numbered steps and group labels. Use pipeline-section to separate phases; keep each row to five steps or fewer."
---

The pipeline layout is for presenting sequential workflows, processes, or phased plans. Steps are numbered and arranged horizontally within a `.pipeline` row, with a `.pipeline-label` naming each group. Multiple groups stack vertically, each separated by a top divider line that is applied automatically by CSS. Use this layout whenever the narrative is about how something is done, not just what was done.

**Default theme:** `light` (workflow diagrams need a clean background for readability)

## Component structure

```
.pipeline-section            ← one group of steps (adds top divider line via CSS)
  .pipeline-label            ← group name / phase label
  .pipeline                  ← horizontal row of steps
    .step                    ← individual step card
      .step-nb               ← step number (e.g. "01")
      .step-title            ← short step name (one or two words)
      .step-desc             ← one-line description of what happens
```

## Using multiple pipeline groups

Add as many `.pipeline-section` blocks as needed — each one gets a top divider line automatically through CSS, creating clear visual separation between groups. You do not need to add any separator markup between groups.

## Step count per row

Keep each `.pipeline` row to a maximum of 5 steps. Beyond 5, the `.step` cards become too narrow to read the `.step-title` and `.step-desc` comfortably. If a workflow has more than 5 steps, split it into a second `.pipeline-section` with its own `.pipeline-label`.

<Tip>
The `.pipeline-section` class automatically adds a top divider line via CSS — this is built into `template.html`. You do not need to add `<hr>` or `border-top` manually between groups.
</Tip>
