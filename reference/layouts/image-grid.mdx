The image grid layout is for presenting multiple screenshots or images as visual evidence. Six images in a 3×2 arrangement (`.grid-3-3`) communicate breadth and scale at a glance — ideal for platform proof (showing follower counts across six networks), product screenshots, or before/after visual comparisons. Use a light background so screenshots read clearly against the slide.

**Default theme:** `light` (screenshots need a bright background for maximum legibility)

## Critical rule: use `height:Nvh`, never `aspect-ratio`

Every `.frame-img` in a grid **must** use a fixed `height:Nvh` value (e.g. `height:26vh`) instead of `aspect-ratio`. This is the most important rule for this layout.

When you use `aspect-ratio` inside a CSS grid cell, the browser calculates the height from the cell width — but grid cells can be unpredictably wide, causing images to blow past the viewport height and push the grid off-screen. A fixed `height:26vh` constrains each image to exactly 26% of the viewport height regardless of screen size, keeping the 3×2 matrix contained within a single slide.

The `.frame-img` class already applies `object-fit:cover + object-position:top center` to all contained `<img>` elements, so images crop from the bottom only — the top of each screenshot (the most informative area) is always visible.

## Grid class options

| Class | Layout | Use when |
|-------|--------|----------|
| `.grid-3-3` | 3×2 (6 images) | Most common — platform proof, full evidence sets |
| `.grid-3` | 3×1 (3 images) | Lighter evidence — three key screenshots |

## Image count options

- **6 images**: use `.grid-3-3` — fills the grid completely, no empty cells
- **4 images**: use `.grid-3-3` but leave two cells empty, or use `.grid-4` for a 2×2 layout
- **3 images**: use `.grid-3` for a single-row presentation with more breathing room per image
