The Magazine Web PPT skill ships with 10 layout skeletons that cover every common slide type in an editorial-style deck: opening covers, act dividers, data grids, narrative slides with images, multi-image comparisons, workflow pipelines, dramatic question pages, key-quote slides, before/after comparisons, and information-dense text-plus-image pages. Every layout is a complete, paste-ready `<section>` block — replace the copy and image paths and you're done.

## Pre-flight reminder

Before you use any layout, confirm that every CSS class it references exists in `template.html`. All classes (`h-hero`, `h-xl`, `h-sub`, `h-md`, `lead`, `meta-row`, `stat-card`, `grid-2-7-5`, `pipeline`, `frame-img`, `callout`, and the rest) are predefined in the `<style>` block of `assets/template.html`. Do not invent new class names — if you need one-off overrides, use inline `style="..."`. For guidance on the full aesthetic system see [Aesthetic](/design/aesthetic); for how layouts fit into a full deck workflow see [Content and layouts](/workflow/content-and-layouts).

## Grid reference

All grid classes are predefined in `template.html` with `gap: 3vw 4vh` by default (overridable per instance).

| Class | Ratio | Use |
|-------|-------|-----|
| `.grid-2-6-6` | 6:6 (1:1) | Equal two-column split |
| `.grid-2-7-5` | 7:5 | Text-dominant column + supporting image |
| `.grid-2-8-4` | 8:4 (2:1) | Large body text + small image or data |
| `.grid-3` | 1:1:1 | Three equal columns (case studies, screenshots) |
| `.grid-3-3` | 3×2 | Six-image matrix |
| `.grid-6` | 3×2 | Six stat cards |

## Page rhythm recommendation

For a 25–30 page deck, hero pages and non-hero pages should alternate at roughly a **2–3 : 1 ratio** — no more than 3 consecutive non-hero pages, and no more than 2 consecutive hero pages. The recommended arc:

1. **Hero Cover** (page 1)
2. **Act Divider** (act opening — `hero light` or `hero dark`)
3. **Big Numbers** (hard data, immediate impact)
4. **Quote + Image** (narrative hook or identity contrast)
5. **Image Grid** (evidence support)
6. **Hero Question** (act close, suspense)
7. … repeat structure for Act II, Act III …
8. **Hero Close** (final page — question or acknowledgment)
